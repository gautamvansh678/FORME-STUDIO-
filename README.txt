FORME STUDIO — CLOTHING STORE WEBSITE
Files: index.html, style.css, script.js
RUN: Open this folder in VS Code and launch index.html using Live Server, or open index.html in your browser.
CUSTOMIZE:
1. In script.js, replace WHATSAPP_NUMBER with your WhatsApp number (country code + number, digits only).
2. Update store name, product names, prices, sizes, descriptions and photos.
3. The bag/cart works in the browser session and sends a demo order through WhatsApp. No payment gateway, stock system or backend is connected.
NOTE: Products/prices are placeholders. Internet is required for online fonts/images.

AGENCY-STYLE POLISH UPDATE:
Added a stronger closing call-to-action, floating WhatsApp contact, sticky blurred navigation, subtle scroll reveal effects, accessibility focus styles and hover polish. Replace all demo contact numbers, business information, products/prices and images before using this as a client project.
